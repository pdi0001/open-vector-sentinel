# Open Vector Sentinel

Open Vector Sentinel is an open-source AI and data platform for climate-sensitive arbovirus early warning.

The project integrates georeferenced mosquito trap data, mobile field inspections, QR-coded sample tracking, molecular testing results, climate variables and AI-based risk interpretation to support earlier and more targeted public health action.

## Project status

The operational surveillance workflow is functional using existing field, laboratory and third-party digital tools. This repository will host the UNICEF-funded open-source digital layer, including data schemas, APIs, dashboard components, AI models, documentation and implementation guides.

## Open-source scope

This repository covers the digital layer of the project:

- Data schemas
- API specifications
- Dashboard components
- AI/ML models
- Sample datasets
- Documentation
- Implementation guides

Trap hardware, industrial molds, proprietary know-how and third-party licensed technologies are outside the open-source scope.

## Intended users

- Municipal health departments
- Vector-control teams
- Schools and child-centered public services
- Researchers and developers working on climate-sensitive disease surveillance

## Roadmap

### Months 1–3
Repository setup, governance, data schema, mobile data forms and dashboard MVP.

### Months 4–6
Pilot deployment, climate-data integration, laboratory-result integration and first AI models.

### Months 7–9
Validation of hotspot detection, alert accuracy and operational usefulness.

### Months 10–12
Public documentation, anonymized datasets, API documentation and replication guides.
